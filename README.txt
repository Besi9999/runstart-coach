RUNSTART COACH - WINDOWS + IPHONE PWA

1. Extract this ZIP.
2. Open Command Prompt in the extracted runstart-coach-iphone folder.
3. Run: npm install
4. Run: npm start
5. Open: http://localhost:3000

For iPhone installation, deploy this app to an HTTPS host first. Then open the HTTPS address in Safari on iPhone -> Share -> Add to Home Screen.

Strava integration is intentionally not enabled in this first installable package. Get the app running first; add Strava OAuth after deployment.
