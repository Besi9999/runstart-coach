How to send a run to Strava

  1. Choose a REAL run and tap Export GPX.
  2. Open Strava Upload in Safari/browser.
  3. Select the GPX file exported by RunStart and complete the Strava upload.

RunStart never sends TEST/simulation data automatically. Manual upload keeps you in control and avoids paid API requirements.
